# Pacotes (voos + hotel + adicionais) — Implementation Plan

> **For agentic workers:** REQUIRED: Use superpowers:subagent-driven-development (if subagents available) or superpowers:executing-plans to implement this plan. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Permitir montar um "pacote de viagem" a partir de N vouchers tipados (voos + hotéis obrigatórios + adicionais de carro/passeio/transfer), gerando e-mail consolidado + página hospedada + PDFs anexados, com timeline cronológica da viagem.

**Architecture:** Novo agregado `packages` (tabela + `package_json`) com schemas por tipo. `packageExtractor` despacha extração por `kind` (reusa `extractVoucher` de voo; prompts Gemini novos para hotel/car/tour/transfer). `combineVouchers` (multidestinos) monta a parte de voo. `packageBlocks` monta uma timeline cronológica única consumida por e-mail e página. PDF do voucher de voo do pacote é renderizado reusando o Playwright via uma rota de preview escopada por pacote.

**Tech Stack:** Node/Express + SQLite + multer + Playwright + Gemini + Jest (backend). React 19 + Vite + Tailwind (frontend). Sem novas dependências.

**Spec:** `docs/superpowers/specs/2026-07-15-pacotes-design.md`

**Comando de teste backend:** `cd backend && npx jest <arquivo> --runInBand`. Sem `GEMINI_API_KEY` os extractors entram em STUB. Testes de rota usam `EXTRACTION_MODE=stub` e o helper `authed()` (retorna `{agent, csrf}`, seta `X-CSRF-Token`). Pré-existentes `auth`/`users` falham na baseline do harness (tabela `monitored_flights_status` ausente no setup) — NÃO é regressão.

**Ordem/fases:** Fase 0 (infra) → Fase 1 (hotel: 1ª fatia vertical ponta-a-ponta) → Fase 2 (adicionais) → Fase 3 (render e-mail/página) → Fase 4 (anexo PDF de voo) → Fase 5 (frontend) → Fase 6 (smoke). Cada task é commitável isoladamente.

```js
const KINDS = ['flight', 'hotel', 'car', 'tour', 'transfer'];
const ADDON_KINDS = ['car', 'tour', 'transfer'];

function validateItem(item) {
  const errors = [];
  const req = (cond, msg) => { if (!cond) errors.push(msg); };
  req(item && typeof item === 'object', 'item inválido');
  if (!item || typeof item !== 'object') return { ok: false, errors };
  req(KINDS.includes(item.kind), `kind inválido: ${item.kind}`);
  req(typeof item.sortDate === 'string' && item.sortDate.length > 0, 'sortDate obrigatório');
  // Campos-âncora mínimos por tipo (não-bloqueante em opcionais):
  if (item.kind === 'hotel') {
    req(item.name, 'hotel.name obrigatório');
    req(item.checkIn && item.checkIn.date, 'hotel.checkIn.date obrigatório');
  } else if (item.kind === 'car') {
    req(item.pickup && item.pickup.datetime, 'car.pickup.datetime obrigatório');
  } else if (item.kind === 'tour') {
    req(item.activity, 'tour.activity obrigatório');
    req(item.datetime, 'tour.datetime obrigatório');
  } else if (item.kind === 'transfer') {
    req(Array.isArray(item.legs) && item.legs.length > 0, 'transfer.legs obrigatório');
  }
  return { ok: errors.length === 0, errors };
}

function validatePackage(pkg) {
  const errors = [];
  const req = (cond, msg) => { if (!cond) errors.push(msg); };
  req(pkg && typeof pkg === 'object', 'pacote inválido');
  if (!pkg || typeof pkg !== 'object') return { ok: false, errors };
  req(pkg.flights && typeof pkg.flights === 'object', 'pacote exige voos (flights)');
  req(Array.isArray(pkg.hotels) && pkg.hotels.length >= 1, 'pacote exige ao menos 1 hotel');
  (pkg.hotels || []).forEach((h, i) => { const r = validateItem(h); if (!r.ok) errors.push(`hotels[${i}]: ${r.errors.join('; ')}`); });
  (pkg.addons || []).forEach((a, i) => { const r = validateItem(a); if (!r.ok) errors.push(`addons[${i}]: ${r.errors.join('; ')}`); });
  return { ok: errors.length === 0, errors };
}

module.exports = { validateItem, validatePackage, KINDS, ADDON_KINDS };
```

```js
// Junta {date:'YYYY-MM-DD', time:'HH:mm'} num ISO com fuso BR (-03:00) como default
// quando o time não trouxer offset. (A hora vem do documento; o fuso do serviço é
// preservado quando o extrator já devolve ISO completo em outros campos.)
function joinDateTime(date, time) {
  if (!date) return null;
  const t = (time && /^\d{1,2}:\d{2}/.test(time)) ? time.padStart(5, '0') : '00:00';
  return `${date}T${t}:00-03:00`;
}

function deriveSortDate(item, kind) {
  if (kind === 'hotel') return item.checkIn ? joinDateTime(item.checkIn.date, item.checkIn.time) : null;
  if (kind === 'car') return item.pickup?.datetime || null;
  if (kind === 'tour') return item.datetime || null;
  if (kind === 'transfer') return (Array.isArray(item.legs) && item.legs[0]?.datetime) || null;
  if (kind === 'flight') return item.trips?.[0]?.departure?.datetime || null;
  return null;
}

function normalizeItem(raw, kind) {
  const item = { ...(raw || {}), kind };
  // Defaults de arrays por tipo (evita null em .map na renderização)
  if (kind === 'hotel') {
    item.rooms = Array.isArray(item.rooms) ? item.rooms : [];
    item.guests = Array.isArray(item.guests) ? item.guests : [];
    item.amenities = Array.isArray(item.amenities) ? item.amenities : [];
  }
  if (kind === 'tour') {
    item.includes = Array.isArray(item.includes) ? item.includes : [];
    item.excludes = Array.isArray(item.excludes) ? item.excludes : [];
  }
  if (kind === 'transfer') {
    item.legs = Array.isArray(item.legs) ? item.legs : [];
  }
  item.sortDate = deriveSortDate(item, kind);
  return item;
}

module.exports = { normalizeItem };
```

```js
async function extractPackageItem(buffer, mimetype, kind) {
```
